# 🛍️ Tienda de Ropa - Alquemia

Bienvenido al repositorio de **Alquemia**, una aplicación web moderna para la gestión y compra de ropa en línea.  
Con Alquemia podrás **explorar un catálogo dinámico**, realizar compras de forma segura y administrar productos fácilmente desde un panel completo.

---

## 🚀 Características

- 📖 **Catálogo de ropa** para mujer y hombre con paginación  
- 🎨 **Selección de colores**: al hacer clic en un color, el producto cambia dinámicamente  
- 🛒 **Carrito de compras** totalmente funcional  
- 💳 **Pagos con PayPal** para usuarios registrados  
- 🔐 **Autenticación y recuperación de contraseña**  
- 📍 **Mapa interactivo** para localizar la tienda y contactarnos fácilmente  
- 📱 **Diseño responsivo**: compatible con móviles, tablets y escritorio  

### 👩‍💼 Funcionalidades de administrador

Los administradores pueden registrarse **únicamente si usan un correo @tiendaalquemia@gmail.com**.  
Desde el **panel de administración** pueden:  
- Gestionar pedidos  
- Agregar, editar y eliminar productos  
- Administrar las relaciones de los productos con colores y tallas  

### 👤 Funcionalidades de usuario

- Explorar el catálogo con paginación  
- Seleccionar colores y ver el cambio en los productos  
- Agregar productos al carrito y realizar pagos con PayPal  
- Contactar a la tienda y localizarla en el mapa
